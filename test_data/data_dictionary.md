# Data Dictionary — Evaluation Dataset

Field names and types below are taken directly from the Django model
definitions in this repository (products/models.py, ecommerce/models.py,
sales/models.py, inventory/models.py, expenses/models.py,
forecasting/models.py, customer_insights/models.py), not invented for
this document.

## products.csv (products.Product)

- id — integer — primary key
- category_id — integer, nullable — foreign key to products.Category
- supplier_id — integer, nullable — foreign key to products.Supplier
- product_name — text (max 200 chars)
- description — text, nullable
- unit_price — decimal (12 digits, 2 decimal places) — in-store price
- quantity_in_stock — integer — current stock level
- reorder_level — integer — threshold below which is_low_stock is true
- is_active — boolean — controls whether product is in forecasting/reporting scope
- is_available_online — boolean — whether product appears in the online store
- online_price — decimal, nullable — price shown in the online store (may differ from unit_price)
- created_at — datetime

No Cost of Goods Sold (COGS) field exists on this model or anywhere in
the schema. This is a deliberate scope decision documented in the
dissertation, not an omission from this export.

## customers.csv (ecommerce.OnlineCustomer)

- id — integer — primary key
- full_name — text (max 200 chars)
- email — text, unique — synthetic address; see README for the marker patterns used
- phone — text (max 20 chars)
- address — text — default delivery address
- credit_limit — decimal (10 digits, 2 decimal places) — max credit for Buy Now Pay Later orders
- credit_balance — decimal (10 digits, 2 decimal places) — current outstanding credit owed
- is_active — boolean
- created_at — datetime — account creation date (backdated by the seed script to simulate a realistic join date relative to first order)
- lifetime_spending — decimal (12 digits, 2 decimal places) — cumulative total of confirmed order amounts
- total_orders — integer (non-negative)
- last_purchase_date — datetime, nullable
- trust_score — integer (0-100), rule-based, recalculated on each confirmed order

Excluded: OnlineCustomer.password (hashed credential; see README).

## online_orders.csv (ecommerce.OnlineOrder)

- id — integer — primary key
- customer_id — integer — foreign key to customers.csv (id)
- order_reference — text, unique — human-readable reference, e.g. ORD-2026-A3F9
- order_date — datetime
- status — text — one of: pending, confirmed, processing, shipped, delivered, cancelled
- payment_method — text — one of: cash_on_delivery, orange_money, afrimoney, credit
- delivery_zone_id — integer, nullable — foreign key to delivery.DeliveryZone (not exported in this dataset)
- delivery_fee — decimal (10 digits, 2 decimal places) — snapshotted at checkout
- delivery_distance_km — decimal (6 digits, 2 decimal places)
- delivery_status — text — one of: assigned, in_transit, delivered, failed (blank if not yet assigned)
- delivery_method — text — one of: own_rider, third_party, customer_pickup (blank if not yet chosen)
- payment_reference — text — synthetic reference generated by the project's simulated payment flow (e.g. COD-XXXXXXXX); not a real payment gateway transaction
- payment_confirmed — boolean
- total_amount — decimal (10 digits, 2 decimal places)
- linked_sale_id — integer, nullable — foreign key to sales.csv (id); set once the order is confirmed and a Sale record is created
- created_at — datetime

## sales.csv (sales.Sale)

- id — integer — primary key
- sale_date — datetime — auto-set at creation (auto_now_add); seeded rows are backdated afterward via a queryset update to reflect realistic historical dates
- total_amount — decimal (12 digits, 2 decimal places)
- status — text — one of: completed, pending, cancelled
- notes — text, nullable — walk-in seed sales are marked with the literal text "[SEED] walk-in sale"; online-order-linked sales may be blank

Excluded: served_by (foreign key to the staff account that recorded the sale).

Two origins are combined in this file: walk-in sales (no customer link,
identified by the notes marker above) and sales created automatically
when a synthetic customer's online order is confirmed (linked via
online_orders.csv -> linked_sale_id). Both are included as they are both
Sale records in the same table.

## sale_items.csv (sales.SaleItem)

- id — integer — primary key
- sale_id — integer — foreign key to sales.csv (id)
- product_id — integer — foreign key to products.csv (id)
- quantity — integer
- unit_price — decimal (12 digits, 2 decimal places) — price at time of sale, may differ from the product's current unit_price

## stock_receipts.csv (inventory.StockReceipt)

- id — integer — primary key
- product_id — integer — foreign key to products.csv (id)
- quantity_received — integer
- receipt_date — datetime — auto-set at creation, backdated for seeded rows same as sale_date above
- notes — text, nullable — seeded rows are marked with the literal text "[SEED] periodic restock" or similar

Excluded: received_by (foreign key to the staff account that recorded the receipt).

## inventory_adjustments.csv (inventory.InventoryAdjustment)

- id — integer — primary key
- product_id — integer — foreign key to products.csv (id)
- adjustment_type — text — one of: addition, deduction
- quantity — integer
- reason — text, nullable — seeded rows are marked with the literal text "[SEED]" as a prefix
- adjusted_at — datetime — auto-set at creation, backdated for seeded rows same as sale_date above

Excluded: adjusted_by (foreign key to the staff account that made the adjustment).

## expenses.csv (expenses.Expense)

- id — integer — primary key
- category_id — integer, nullable — foreign key to expenses.ExpenseCategory (not exported separately in this dataset; category names are: Rent, Electricity, Internet, Transportation, Delivery, Staff/Salaries, Packaging, Maintenance, Marketing, Utilities)
- description — text (max 255 chars) — seeded rows are marked with the literal text "[SEED]" as a prefix
- amount — decimal (12 digits, 2 decimal places)
- expense_date — date
- created_at — datetime

Excluded: recorded_by (foreign key to the staff account that recorded the expense).

## demand_forecasts.csv (forecasting.DemandForecast)

Only the latest row per product is included (see README for why). In the
live database this table holds full generation history; here it is
reduced to current state.

- id — integer — primary key
- product_id — integer — foreign key to products.csv (id)
- forecast_period_start — date
- forecast_period_end — date
- predicted_quantity — decimal (10 digits, 2 decimal places), nullable
- historical_average — decimal (10 digits, 2 decimal places), nullable
- trend — text, nullable — one of: increasing, stable, decreasing
- confidence_score — decimal (5 digits, 2 decimal places), nullable — 0 to 100, derived from model fit (R-squared)
- recommended_restock_quantity — decimal (10 digits, 2 decimal places), nullable — computed as max(0, predicted_quantity minus current stock) at time of generation
- has_sufficient_data — boolean
- insufficient_data_message — text, nullable — explanation shown when has_sufficient_data is false
- generated_at — datetime — auto-set at creation
- model_version — text — e.g. v1.0-linreg (scikit-learn LinearRegression, per project architecture)

## customer_insights.csv (customer_insights.CustomerInsightSnapshot)

Only the latest row per customer is included (see README for why). In
the live database this table holds full generation history; here it is
reduced to current state.

- id — integer — primary key
- customer_id — integer — foreign key to customers.csv (id)
- generated_at — datetime
- segment — text — one of: vip, loyal, new, at_risk, price_sensitive, premium_shopper, frequent_buyer
- avg_order_value — decimal (10 digits, 2 decimal places), nullable
- order_frequency_days — float, nullable
- favorite_category_id — integer, nullable — foreign key to products.Category (not exported separately in this dataset)
- preferred_payment_method — text, nullable
- preferred_shopping_time — text, nullable — e.g. morning, afternoon, evening, night
- has_sufficient_data — boolean
- prediction_method — text — one of: ml, rule_based
- churn_risk_score — float, nullable — 0.0 to 1.0 probability
- predicted_next_purchase_date — date, nullable
- estimated_lifetime_value — decimal (12 digits, 2 decimal places), nullable
- ai_summary_text — text, nullable — free-text summary generated for staff-facing display; spot-checked prior to export and confirmed to reference only synthetic customer names already present in customers.csv
- recommended_product_ids — JSON list of integers — product IDs recommended for this customer
- model_version — text

## customer_events.csv (customer_insights.CustomerEvent)

- id — integer — primary key
- customer_id — integer, nullable — foreign key to customers.csv (id); nullable in the live schema to allow guest browsing, but every row in this export has a customer_id since only synthetic-customer events were included
- session_key — text, nullable — session identifier; values in this export are either empty or synthetic-session placeholders generated by the seed script, not real user session tokens
- event_type — text — one of: product_view, category_view, search_query
- product_id — integer, nullable — foreign key to products.csv (id)
- category_id — integer, nullable — foreign key to products.Category (not exported separately in this dataset)
- search_term — text, nullable — populated only when event_type is search_query
- created_at — datetime
